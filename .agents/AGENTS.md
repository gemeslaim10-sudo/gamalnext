# Repository Rules & Constraints

## CV Design, Structure, Dimensions & Print Constraints
- **Sacred & Unalterable**: The visual design, component layout structure, A4 dimensions/sizing, and print implementation for CV pages (`CvTemplate`, `gamal-cv`, `ai-cv-builder`, and CV printing styles) are sacred and MUST NEVER be altered or modified.
- **Allowed Usage**: These components and print styles can be consumed, displayed, and referenced, but their HTML/CSS structure, sizing (A4 210mm x 297mm), layout hierarchy, and `@media print` rules must remain strictly preserved without modifications.
